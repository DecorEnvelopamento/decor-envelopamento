# Decor Envelopamento CWB

Site estático publicado pelo GitHub Pages em [decorenvelopamentocwb.com.br](https://decorenvelopamentocwb.com.br/).

- `/` — envelopamento de móveis e ambientes (`index.html`).
- `/wrap/` — Decor Wrap Concept, envelopamento automotivo e PPF (`wrap/index.html`).

A publicação usa a branch `main`, com os arquivos servidos diretamente da raiz. O domínio personalizado está em `CNAME`. Não há etapa de build.

Para adicionar fotos à galeria automotiva, siga `wrap/fotos/LEIA-ME.txt` e coloque os arquivos na pasta `wrap/fotos/`.
